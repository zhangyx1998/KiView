# Blinky

Tiny two-layer KiCad 10 sample board (30 x 20 mm): a 2-pin +5V/GND header, 100 nF decoupling capacitor on the back side, and a 330 R + red 0805 LED on the hierarchical "LED driver" sheet, with an M3 mounting hole and a filled GND zone on B.Cu. Used as a test fixture for KiView.

The design files in this folder are dedicated to the public domain under CC0 1.0. The library symbols and footprints embedded in them come from the official KiCad libraries, licensed CC-BY-SA 4.0 with the KiCad libraries design exception (designs using them may be licensed freely).
